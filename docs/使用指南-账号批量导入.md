# 账号批量导入使用指南

> 适用版本：Black Hole 2.0+ · 对应接口 `POST /api/users/import`
> 示例文件：[`docs/examples/users-sample.csv`](./examples/users-sample.csv)

批量导入用来一次性建好 **500 人以内**的账号。每个人的**初始密码由服务端随机生成、只显示一次**，
所以请按下面的顺序操作，别中途关闭页面。

---

## 一、谁能导入

| 角色 | 能导入普通用户 | 能导入管理员 |
|---|---|---|
| 超级管理员（`is_super=true`） | ✅ | ✅ |
| 管理员（`is_super=false`） | ✅ | ❌ 整批拒绝（403），不会"悄悄降级成普通用户" |
| 普通用户 | ❌ | ❌ |

> CSV 里只要出现一行 `角色=admin`，非超管提交会**整批失败**，一行都不会导入。
> 要加管理员，请让超级管理员来导。

---

## 二、准备 CSV 文件

只有三列，表头必须一字不差：

```csv
姓名,账号,角色
张伟,zhangwei,user
李娜,lina,user
吴磊,wulei,admin
```

| 列 | 规则 |
|---|---|
| 姓名 | 1~64 个字符，可以中文 |
| 账号 | **4~32 位，字母开头**，只能字母/数字/下划线（`zhang_wei` 可以，`zhang-wei` 不行） |
| 角色 | `user` 或 `admin`，小写 |

其它要求：

- 编码 **UTF-8**（Excel 另存为「CSV UTF-8」；带不带 BOM 都行）
- 最多 **1000 个数据行/文件**，超过要分批导
- 字段里有逗号时用双引号包起来；**不支持字段内换行**
- 账号在文件内重复、或库里已存在 → 该行**跳过**（计入 `skipped`，不报错）
- 其它格式问题（账号不合规、角色写错）→ 该行**失败**并给出行号，**其余行照常导入**

> 部门不写在 CSV 里，是在导入弹窗里**选一个末级组织节点**，这一批人全部挂到该节点下。

---

## 三、操作步骤（界面）

1. 用**超级管理员或管理员**登录；
2. 左侧「设置 → 账号管理」；
3. 右上角点 **「批量导入」**；
4. 选择这批人要挂到的**部门（末级节点）**；
5. 选好 CSV 文件 → 确定；
6. 等结果弹窗，里面会给出：
   - 成功 / 跳过 / 失败 的条数
   - **每个新账号的初始密码（只显示这一次）**
7. **立刻把这份账号+密码清单复制走**（发到内部群或导进表格），关掉弹窗就再也拿不到了。

> 忘了保存怎么办：到「账号管理」里对这个人点「重置密码」，会重新生成一个一次性密码。

---

## 四、导入之后

- 每个新账号的 `must_change_password = true`：**第一次登录必须先改密码**，
  改之前除「改密/退出」外的接口一律 403（页面会直接跳改密页）。
- 密码策略：8~64 位，至少一个字母 + 一个数字。
- 导入是**同步接口**：500 人约 12 秒（8 vCPU 机器实测），期间页面会一直转圈，不要重复点。
  一次导不完就拆成几批（每批 ≤1000 行，建议 ≤500 行/批）。

---

## 五、常见错误对照

| 提示 | 原因 | 怎么改 |
|---|---|---|
| `CSV 表头必须是 姓名,账号,角色` | 表头多了/少了列、有空格、用了英文逗号以外的分隔符 | 严格按第二节的表头 |
| `最多导入 1000 行，当前 N 行` | 单文件超上限 | 拆成多个文件分批导 |
| `只有超级管理员才能导入管理员账号` | 文件里有 `admin` 行，提交人不是超管 | 换超管导，或把该行改成 `user` |
| 某行 `账号格式不对` | 少于 4 位、数字开头、带 `-` 或中文 | 按账号规则改名 |
| 某行 `角色只能是 user 或 admin` | 写成「普通用户」「管理员」等中文 | 改成 `user` / `admin` |
| `请选择部门` | 没选组织节点 | 先选末级节点（不能选非末级） |
| 全部行都进了 `skipped` | 库里已经有这些账号 | 正常现象；要重置密码请用「重置密码」 |

## 六、自检 / 命令行方式（运维用）

仓库里带了一份示例文件和自检脚本，可以在验收环境先跑一遍确认导入链路是通的：

```bash
# 会真的导入 10 个账号，抽查登录，然后把它们删掉
SEED_ADMIN_PASSWORD=*** \
DATABASE_URL=postgres://... \
node scripts/check-sample-import.mjs --base http://localhost:5173
```

输出示例：

```
导入状态=200 耗时=2836ms
  "success": 10, "skipped": 0, "failed": 0
抽查登录 zhangwei → 200
已清理 10 个测试账号
```

批量生成 CSV（比如压测用的 500 行）：

```bash
node -e "const fs=require('fs');const r=['姓名,账号,角色'];for(let i=1;i<=500;i++)r.push('用户'+i+',user'+String(i).padStart(4,'0')+',user');fs.writeFileSync('users-500.csv','\ufeff'+r.join('\n'))"
```

> ⚠️ 删除账号时要注意外键顺序：`session → workspace_layout → workspace → app_user`
> （这几张表都没配 ON DELETE CASCADE，直接删用户会报 23503）。
