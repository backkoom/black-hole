## 一、是什么

内网项目管理系统 **Black Hole**。前后端分离的 BS 架构：

```
浏览器  React 18 + Vite + Ant Design 5
   │  fetch /api/*   同源，不启用 CORS
   ▼
nginx  静态产物 + 反向代理（双 API 实例）
   ▼
Fastify 5  Node 22 + TypeScript strict + zod + 手写参数化 SQL
   ▼
PostgreSQL 18
```

不引入 Redis / 消息队列 / CDN / ORM。会话存库、文件落盘、备份走 pg_dump。

## 三、做完的

### 功能
- **用户端 5 个模块**（D-23/D-24 两次重构）：工作台 / 项目管理（年度规划·工作看板·任务·周进度·问题风险 5 视图）/
  团队协作 / 日程安排 / 文件资料 + 设置
- **工作台 = 数据看板 + 下钻**（D-24）：六张时间卡（我的工作/今日/周/月/季/年，点数字进对应页面）、
  任务状态、随记、团队成员、年度工作规划；原「数据统计」整页内嵌为工作台的「数据看板」，独立入口取消
- **管理端**：自定义工作台（12 模块拖拽）、账号（含 CSV 批量导入）、组织架构、工作台模板、系统设置
- **文件**：真上传/下载（multipart 落盘、sha256、防目录穿越、删除清盘、50MB 上限）
- **团队协作**：公告 / 讨论 / 审批（提交与决策）
- **日历**：农历、二十四节气、传统节日、法定节假日「休/班」角标
- **甘特图**：项目级时间条 + 里程碑菱形 + 今日线 + 阶段背景带

## 四、怎么验（三条命令）

```bash
# 单测 + 类型 + lint
npm run typecheck && npm run lint && npm run test

# 端到端（需本地 5173 + 3000 起着）
npm run test:e2e

# 线上冒烟（自签环境带 --insecure）
SEED_ADMIN_PASSWORD=*** bash deploy/smoke.sh https://192.168.102.102 --insecure

# 布局体检（十页 × 五视口）
SMOKE_PW=*** PROBE_PAGES="|kanban|tasks|calendar|progress|analytics|team|files|risks|settings" \
  node scripts/probe-layout.mjs https://192.168.102.102 admin

# 工作台演示数据（可重复灌，按固定标题先删后建，不会重复堆积）
DEMO_BASE=https://192.168.102.102 DEMO_INSECURE=1 SEED_ADMIN_PASSWORD=*** \
  node scripts/seed-workbench.mjs

# 工作台实拍 + 六张卡"点数字进页面"穿透校验
SHOT_BASE=https://192.168.102.102 SHOT_INSECURE=1 SEED_ADMIN_PASSWORD=*** \
  node scripts/shot-workbench.mjs
```

其他工具脚本：`perf-seed.mjs` / `perf-check.mjs`（500 人规模）、`perf-upload.mjs`（上传压测）、
`check-sample-import.mjs`（示例 CSV 自检）、`brand-assets.py` + `set-brand.cmd`（换 logo）。

## 五、还有限制 / 二期可做

### 已知限制（不影响使用）
- 管理员 `/api/tasks` 不分页：12.5 万行 120ms 还能接受，数据再翻十倍要加分页
- 通知：已有站内通知（任务到期/逾期，顶栏铃铛）；不含邮件/短信外发
- 窄屏：≤1280 时看板标签栏、甘特时间轴会出现横向滚动（按设计可滚，非破版）

### 二期候选（待定优先级）
1. 文件版本历史（上传新版本、回滚、对比）
2. 站内通知与提醒（任务到期、审批待办）
4. 导出（任务清单 / 统计报表 → Excel/PDF）
6. 移动端适配（≤1024）
