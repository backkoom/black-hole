## 全局设计基线

#### 布局与尺寸

- 中文界面；AntD 5 默认组件；主色用 AntD 默认蓝，不做品牌定制也能交付。（执行包 §8.1）
- 字体：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`；正文 14px；页面标题 20px。（执行包 §8.1）
- 间距：4/8/12/16/24/32；卡片圆角 8px；边框 `#f0f0f0`；背景 `#f5f7fa`；内容卡片白底。（执行包 §8.1）
- 桌面优先；最小支持 1024px；小于 1024px 页面横向滚动，不压缩 12 列；不做手机端。（执行包 §8.1；v2 §4.4 同口径）
- 所有页面：顶部页面标题 + 右侧主操作；内容区最大宽度 1440px；设置页左侧子导航 200px。（执行包 §8.1）
- 所有表格：分页、空状态、加载态；操作列固定在右侧；删除用 Popconfirm。（执行包 §8.1）
- 所有表单：AntD Form；必填星号；提交按钮 loading；服务端错误显示在表单顶部或字段下。（执行包 §8.1）
- 所有接口失败：`message.error` + 页面内重试；不能只 `console.error`。（执行包 §8.1）
- 所有时间显示：`dayjs.tz(value, 'Asia/Shanghai').format('YYYY-MM-DD HH:mm')`；不用浏览器本地时区。（执行包 §8.1）
- 所有图标：`@ant-design/icons`；不引第二套图标库。（执行包 §8.1）
- 可访问性：按钮有文字或 `aria-label`；表单 label 关联；颜色不是唯一状态表达。（执行包 §8.1）
- 工作台画布：12 列；列间距 16px；行高 72px；画布左右内边距 24px；最大宽度 1440px 居中；视口小于 1024px 时页面横向滚动。（v2 §4.4；执行包 §3.5、§7.6）

#### App Shell

- 左侧固定 220px：产品名「工作台」、四项导航（工作台、任务管理、项目管理、设置）。（执行包 §8.2）
- 右侧顶部：当前用户名、角色标签、退出；不显示搜索/通知/AI。（执行包 §8.2）
- 左侧导航固定四项，不显示知识库、AI 助手、通知、搜索；这些不在一期，不占导航。（v2 §3.2）
- 设置页：左侧子导航（个人资料、修改密码；管理员追加账号管理、组织架构、工作台模板）。（执行包 §8.2；v2 §3.2）
- 普通用户不显示管理入口；直接访问管理路由显示 403 页面。（执行包 §8.2）
- 未登录访问受保护路由跳 `/login`，登录后回原路由。（执行包 §8.2；v2 §3.3）
- 会话态：`HttpOnly` Cookie `sid`，`Secure`/`SameSite=Lax`/`Path=/`/`Max-Age=7 天`；前端不读 token。（执行包 §3.3、§6.1）

#### 空·错·加载态

- 首次加载骨架屏；超过 3 秒失败态。（执行包 §8.8；v2 §4.8 同口径）
- 空状态有图标、文案、可选行动按钮；不能白屏。（执行包 §8.8）
- 403 页面「没有权限」；404 页面「页面不存在/资源不存在」；不显示堆栈。（执行包 §8.8；v2 §3.3 同口径）
- 表单 422 显示字段错误或顶部 message；409 显示冲突弹窗。（执行包 §8.8）
- 网络断开：页面顶部 Alert + 重试；不吞异常。（执行包 §8.8；v2 §3.3 同口径）
- 未登录访问受保护页面：跳 `/login`，登录后回原路由；`must_change_password = true`：除修改密码和退出外，其他页面一律跳 `/settings/password`。（v2 §3.3）

#### 明确不做

- 不做暗色模式、国际化、手机端、拖拽自由布局、模块市场、图表库、富文本、图片上传、通知中心、全局搜索、AI 对话。（执行包 §8.9）
- 不复制 demo 的硬编码 KPI 数字、假头像、假项目、假组织人员。（执行包 §8.9）
- 不为了「好看」新增页面或模块。（执行包 §8.9；v2 §1.5 范围变更规则）
- 一期不做：AI 助手、知识库、文件上传与在线预览、通知、全局搜索、操作日志、业务数据导出（导入结果的一次性密码 CSV 除外）。（v2 §1.3）
- 一期不做：角色自定义、字段级权限、行级权限、部门可见工作台；手机端、实时协同、低代码、对外网访问、SSO、AD/企业微信集成；提示词管理界面、附件管理界面。（v2 §1.3）
- 一期不做布局自动快照与历史版本回滚，版本冲突由用户显式选择。（v2 §4.10）

## 页面详解

### 1. /login 登录

- **可见角色**：公开
- **关键组件**：
  - 居中卡片 360px
  - 账号/密码
  - 错误 Alert
  - 锁定提示
- **组件树**：
  ```
  LoginPage
  └─ Card(360px, 居中)
     ├─ Form(account, password)
     │  ├─ Input(account)
     │  ├─ Input.Password(password)
     │  └─ Button(提交, loading)
     └─ Alert(错误 / 锁定提示)
  ```
- **字段与校验**：
  - `account`：4 至 32 位，字母开头，字母/数字/下划线；统一小写存储；唯一。（执行包 §6.5）
  - `password`：8 至 64 位，至少一个字母和一个数字；不要求特殊字符。（执行包 §6.5）v2 口径为「至少 8 位，含字母和数字」。（v2 §7.4）冲突时取更严的执行包上限，不放宽 v2 下限。
  - 登录错误不区分「账号不存在」和「密码错误」，统一提示；锁定提示可以说明已锁定。（v2 §7.4；执行包 §3.3、§6.3）
- **关键交互**：
  - 登录成功跳工作台；`must_change_password = true` 跳 `/settings/password`。（执行包 §8.3）
  - 连续 5 次密码错误：`locked_until = now() + 10 分钟`；锁定期内正确密码也拒绝；成功登录清零；锁定到期后 `failed_attempts` 归零。（v2 §7.4；执行包 §3.3）
  - `status != active` 按账号或密码错误返回 401，不创建 session。（执行包 §3.3）
  - 登录接口也校验 Origin/Referer 同源。（执行包 §3.3）
- **空/错/加载态**：
  - 提交按钮 loading；服务端错误显示在表单顶部或字段下。（执行包 §8.1）
  - 错误用 Alert 呈现；锁定单独提示。（执行包 §8.3）
  - 失败不泄露账号是否存在。（执行包 §8.3；v2 §12 A1）
- **必须覆盖**：成功跳工作台；must_change 跳改密；失败不泄露账号
- **出处**：v2 §3.1、§3.3、§7.4 / 执行包 §8.3、§8.1、§6.3、§6.5、§3.3

### 2. /workspace 工作台

- **可见角色**：全部
- **关键组件**：
  - 标题/副标题
  - 4 指标卡
  - 编辑器
  - 模块库抽屉
  - 模块配置
  - 保存/预览
- **组件树**：
  ```
  WorkspacePage
  ├─ PageHeader(标题「我的工作台」/ 副标题可空 / 编辑·预览切换 / 保存按钮)
  ├─ MetricsRow(一行 4 个)
  │  ├─ MetricCard(今日任务: 总数 / 已完成)
  │  ├─ MetricCard(进行中: 总数 / 今日到期)
  │  ├─ MetricCard(项目进度: 活跃项目数 + 列表)
  │  └─ MetricCard(本周完成率: 百分比或 —)
  ├─ GridCanvas(12 列 / 行高 72px / gap 16px)
  │  └─ ModuleCard(moduleKey, w, h, config)
  │     └─ ConfigPanel(仅 content 模块)
  ├─ ModuleLibraryDrawer(5 分类 / 占位模块置灰带「迭代」角标)
  └─ VersionConflictModal(刷新丢弃本地 / 覆盖保存)
  ```
- **字段与校验**：
  - 工作台 `name`：1 至 128；`subtitle`：0 至 256，去首尾空格，空 subtitle 存 `null`。（执行包 §6.5）`name` 默认「我的工作台」。（v2 §9.5）
  - 布局保存必须带 `version`；`version` 从 1 开始，每次布局保存 +1。（v2 §4.10；执行包 §3.5）
  - 模块宽 `w` 只能取 3/4/6/12；高 `h` 为 2 至 12 的整数，且不得小于该 `moduleKey` 的 `minSize`；`divider` 固定 `w=12, h=2`，不允许缩放。（v2 §4.4；执行包 §6.5、§7.6）
  - 同一 workspace 同一 `module_key` 只能一条，`divider` 除外；`divider` 最多 3 条；总模块数最多 14。（v2 §4.3、§9.6；执行包 §3.5）
  - `config` 按模块 schema 校验，总大小不超过 64KB；未知字段忽略不报错。（v2 §4.7；执行包 §6.5、§7.3）
  - 模块宽度档位之外不允许停留；高度不允许小于 2 行。（v2 §4.3、§4.4）
- **关键交互**：
  - 添加：从模块库拖入或双击，按指针所在模块的中点插入该模块前/后；插入序号只存 `sort`，不存 `x/y`。（v2 §4.3；执行包 §7.6）
  - 排序：先移除再按调整后的索引插入，避免向下拖动差一位；排序后重排 `sort = 0..n-1`，保存时整份提交。（v2 §4.3）
  - 缩放：宽度吸附到 3/4/6/12；高度取整到 2–12 行；不小于 `minSize`。（v2 §4.3、§4.4）
  - 删除：二次确认；删除后立即重排 `sort`；删除内容模块的确认文案要提示会丢 `config`。（v2 §4.3；执行包 §7.6）
  - 编辑内容：文本、公告、链接、嵌入、图片墙、分割线通过侧边面板改 `config`；保存时校验 `config` schema；内容按纯文本渲染，不执行 HTML。（v2 §4.3、§4.11；执行包 §3.7）
  - 预览：隐藏模块库、删除按钮、缩放手柄，只读渲染；预览不写库。（v2 §4.3）
  - 保存：有未保存改动离开页面要提示；成功更新本地 `version`；失败保留本地改动并提示重试；`localStorage` 只做草稿，不作权威存储。（v2 §4.3）
  - 版本冲突：服务端返回 409 并带当前 `version` 和布局；弹窗两个选项「刷新」（丢弃本地改动加载服务端布局）与「覆盖」（以服务端当前 `version` 为基础再提交本地布局，必须二次确认，不能静默覆盖）。（v2 §4.10）
  - 名称/副标题保存不参与版本号，单独 PUT，不触发 409。（v2 §4.10；执行包 §3.5）
  - 前三张指标卡数据来自 `/stats/overview`；项目进度卡另取 `GET /projects?pageSize=100` 并按口径过滤未完成项目。（执行包 §8.4）
- **空/错/加载态**：
  - 页面无模块时显示「从模块库添加第一个模块」，不要空白画布。（执行包 §8.4）
  - 每个模块必须有 `emptyState`；无数据时显示图标、文案、可选行动按钮。（v2 §4.8）
  - 接口失败显示「加载失败」和「重试」，不能白屏，不能显示假数据。（v2 §4.8；执行包 §7.5）
  - 骨架屏只用于首次加载，超过 3 秒转失败态。（v2 §4.8；执行包 §7.5、§8.8）
  - 占位模块的 `emptyState` 写「功能迭代中」，并显示「迭代」角标。（v2 §4.8）
  - 409 弹窗两个按钮；覆盖后 `version` 用最新。（执行包 §8.4、§8.8）
  - 项目进度卡失败显示「加载失败/重试」，不显示 0 冒充。（执行包 §8.4）
- **必须覆盖**：空状态、失败态、409、草稿提示；content 模块可配置
- **出处**：v2 §3.1、§4.1–§4.11 / 执行包 §8.4、§8.8、§7.5、§7.6、§6.5、§3.5

### 3. /tasks 任务管理

- **可见角色**：全部
- **关键组件**：
  - 筛选栏
  - 表格
  - 状态 Tag
  - 优先级
  - 截止日
  - 项目
  - 新增/编辑 Modal
- **组件树**：
  ```
  TasksPage
  ├─ FilterBar(关键字 / 今日 / 逾期 / 本周 / 项目下拉 / 状态下拉 / 重置)
  ├─ Table(标题 / 项目 / 状态 / 优先级 / 截止日 / 操作)
  │  ├─ StatusTag(行内改状态 → PATCH /api/tasks/:id/status)
  │  └─ RowActions(编辑 / 删除 Popconfirm)
  ├─ TaskFormModal(新增 / 编辑: 标题、项目、优先级、截止日)
  └─ Pagination(page 从 1 起, pageSize 默认 20 最大 100)
  ```
- **字段与校验**：
  - `title`：必填，1 至 256 字。（v2 §5.1；执行包 §6.5）
  - `status`：`todo`/`doing`/`done`；新建默认 `todo`。（v2 §5.1、§5.2）
  - `priority`：`low`/`medium`/`high`；新建默认 `medium`。（v2 §5.1、§5.2）
  - `due_date`：可空；只到日，不带时间；格式 `YYYY-MM-DD`。（v2 §5.1；执行包 §6.5）
  - `project_id`：可空；非空时必须属于任务归属人（不按当前操作人，管理员代改也按任务归属人校验）。（v2 §5.2；执行包 §6.5）
  - `keyword`：1 至 64，大小写不敏感，匹配 `title` 子串；空字符串按未传处理。（执行包 §6.5）
  - `due` 筛选：`today` / `overdue` / `week`；三种筛选都排除已删除任务。（v2 §5.3；执行包 §6.5）
  - 列表默认按 `created_at` 倒序，分页 20；响应带 `projectName`（JOIN `project.name` 的计算字段，不落库），`projectId` 为空时为 `null`。（v2 §5.3）
- **关键交互**：
  - 行内改状态用 PATCH；从非 done 改 done 时写 `done_at = now()`；已经是 done 再提交 done 不改变原 `done_at`；从 done 改回其他状态时清空 `done_at`。（v2 §5.2；执行包 §6.4、§6.5）
  - 允许任意状态互转，不做工作流。（v2 §5.2）
  - 删除用 Popconfirm，软删；删除后列表、统计、项目进度都不再计入。（v2 §5.2；执行包 §8.5）
  - 逾期 = `due_date < 今天` 且 `status <> done` 且未删除；本周 = `due_date` 在本周一至周日。（v2 §5.3）
  - 截止日只用于筛选和逾期判断，不自动改状态。（v2 §5.2）
  - 新建任务只能归属当前登录用户；`POST /tasks` 没有 `userId`，管理员也不能代建。（v2 §5.2；执行包 §6.5）
  - done 后行内显示完成时间。（执行包 §8.5）
- **空/错/加载态**：
  - 空状态「还没有任务，新建一个」；失败态重试。（执行包 §8.5）
  - 表格统一分页、空状态、加载态；操作列固定在右侧；删除用 Popconfirm。（执行包 §8.1）
  - 首次加载骨架屏；超过 3 秒失败态。（执行包 §8.8）
  - 422 显示字段错误或顶部 message。（执行包 §8.8）
- **必须覆盖**：今日/逾期/本周/项目/状态；分页；软删
- **出处**：v2 §3.1、§5.1–§5.3 / 执行包 §8.5、§8.1、§8.8、§6.4、§6.5

### 4. /projects 项目管理

- **可见角色**：全部
- **关键组件**：
  - 卡片/表格二选一（建议卡片）
  - 进度条
  - 状态
  - 新建 Modal
- **组件树**：
  ```
  ProjectsPage
  ├─ ProjectCardGrid(卡片/表格二选一，建议卡片)
  │  └─ ProjectCard(项目名 / 负责人 / 截止日 / 进度条 / x-y 完成 / 状态 Tag)
  ├─ ProjectFormModal(新建: 名称必填、负责人可空、截止日可空)
  └─ Pagination(page 从 1 起, pageSize 默认 20 最大 100)
  ```
- **字段与校验**：
  - `name`：必填，1 至 128 字。（v2 §6.1；执行包 §6.5）
  - `owner`：负责人姓名，可空，最长 64。（v2 §6.1；执行包 §6.5）
  - `due_date`：可空，`YYYY-MM-DD`。（v2 §6.1；执行包 §6.5）
